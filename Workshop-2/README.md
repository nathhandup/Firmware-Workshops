Workshop-2 discussed communication protocols.

This arduino sketch used a simple wiring setup including two ESP32's.
These two ESP32's were connected to eachothers 3v3, GND, RX and TX 
(one ESP's TX connected to the others RX, and RX connected to TX.)

Showcases basic communication between two controllers. Talks about baudrate, 
read through texas instruments documentation on how information is deciphered.
